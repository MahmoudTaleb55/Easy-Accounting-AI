أنت خبير عالمي في تصميم وتجربة المستخدم UI/UX وبناء مواقع SaaS ومنتجات Fintech وAccounting عالمية المستوى. 
مهمتك هي إعادة تصميم موقعي وتطبيق المحاسبة الذكي بالكامل ليظهر كمنتج عالمي فاخر، احترافي، موثوق، و"Category-Defining" أي يبدو كأنه الأول من نوعه في العالم، وليس مجرد موقع خدمات أو صفحة تقليدية.

أريدك أن تتعامل مع المشروع على أنه:
- منصة محاسبة ذكية مدعومة بالذكاء الاصطناعي
- نظام مالي وإداري شامل للأفراد والشركات والمتاجر والمؤسسات
- منتج عالمي يمكنه منافسة أفضل منتجات SaaS وFintech الحديثة
- تصميمه يجب أن يبني الثقة، يوضح القوة، ويُشعر المستخدم أن هذا منتج Enterprise + AI + Future-ready

الهدف:
حوّل التصميم الحالي من تصميم ضعيف/تقليدي/رتيب إلى تجربة بصرية عالمية خرافية، نظيفة، ذكية، متقدمة، غنية بالأقسام، ومصممة بعقلية شركات عالمية مثل Stripe وMercury وBrex من ناحية الوضوح، الثقة، البنية، وسرد القيمة.

المطلوب منك:
1) إعادة بناء الهوية البصرية كاملة:
- تصميم فاخر جدًا وحديث
- أسلوب عالمي Premium SaaS + Fintech
- ألوان احترافية توحي بالثقة والذكاء والاستقرار المالي
- Typography احترافية جدًا
- مساحات بيضاء ذكية
- Visual hierarchy قوية
- تصميم لا يبدو قالبًا جاهزًا أو تصميم AI مكرر

2) إعادة بناء الصفحة الرئيسية بالكامل لتشمل أقسام عالمية احترافية مثل:
- Hero section استثنائي جدًا مع عنوان قوي عالمي
- شريط ثقة أو Social Proof
- مشكلة السوق + كيف نحلها
- لماذا هذا التطبيق مختلف؟
- عرض أهم الميزات بطريقة غير تقليدية
- لقطات UI احترافية للتطبيق
- قسم الذكاء الاصطناعي في المحاسبة
- قسم automation / workflows / smart insights
- قسم الأمان والامتثال والثقة
- قسم التقارير ولوحات التحكم
- قسم الفواتير والمصروفات والضرائب والمخزون إن وجد
- قسم integrations
- قسم مخصص لأصحاب الشركات والمحاسبين والفرق
- مقارنة أو تموضع يوضح لماذا المنتج أقوى من الحلول التقليدية
- testimonials أو use cases
- FAQ احترافي
- CTA نهائي قوي جدًا
- Footer عالمي غني ومنظم

3) أريد بنية محتوى تجعل المنتج يبدو:
- ثوري
- متقدم تقنيًا
- سهل الاستخدام
- موثوق ماليًا
- مناسب للشركات الصغيرة والمتوسطة والكبيرة
- قابل للتوسع عالميًا

4) صمّم الموقع بعقلية conversion + branding + trust:
- كل Section يجب أن يخدم هدفًا واضحًا
- كل CTA مدروس
- لا تكديس عشوائي للعناصر
- لا بطاقات Features تقليدية مكررة
- لا أيقونات داخل دوائر ملونة بشكل مبتذل
- لا ألوان مزعجة
- لا ازدحام
- لا تكرار بصري

5) أريد أيضًا نظام تصميم احترافي للتطبيق نفسه:
- Dashboard عالمي
- Sidebar احترافي
- KPI cards راقية
- جداول مالية حديثة
- إحصائيات ورسوم منظمة
- شاشات فواتير
- شاشات العملاء
- شاشات القيود والمعاملات
- شاشات التقارير
- شاشات الذكاء الاصطناعي والمساعد المحاسبي
- حالات Empty / Loading / Error مصممة بعناية
- Light mode + Dark mode
- تصميم responsive فاخر جدًا على الجوال والديسكتوب

6) أريد من التصميم أن يلتزم بالقوانين والأسس الاحترافية التالية:
- تصميم SaaS/Fintech عالمي وليس تصميم شركة محلية تقليدي
- وضوح شديد في القيمة المقترحة
- hierarchy ممتازة
- كثافة معلومات مدروسة
- أزرار واضحة
- اتساق بصري كامل
- شبكة Layout احترافية
- تناسق spacing
- contrast ممتاز
- قابلية قراءة ممتازة
- سهولة تنقل عالية
- accessibility محترمة
- سرعة وتحميل بصري ذكي
- ثقة عالية جدًا في كل شاشة

7) أريد منك أن تبني Concept بصري فريد للتطبيق:
- ليس Template
- ليس Copy/Paste
- ليس Generic AI look
- أريد Concept أصلي يشعر المستخدم أنه منتج مليار دولار
- اجعل الهوية “future accounting operating system”
- اجعل الانطباع: Intelligent Finance OS

8) قدّم لي المخرجات التالية:
- تصور إبداعي شامل للهوية
- color palette احترافية مع تفسير
- font pairing احترافية
- layout system
- design system
- section-by-section structure
- CTA strategy
- UI components list
- dashboard structure
- content hierarchy
- micro-interactions suggestions
- motion direction
- trust-building elements
- premium visual directions
- نماذج نصوص Headlines وSubheadings احترافية

9) اكتب لي أيضًا:
- أفضل عنوان Hero عالمي
- أفضل Subtitle
- 3 نسخ مختلفة للـ value proposition
- 10 عناوين أقسام احترافية
- 10 CTA buttons قوية
- نصوص تسويقية احترافية قصيرة لكل قسم

10) مهم جدًا:
- أريد الناتج باللغة العربية أو الإنجليزية الاحترافية حسب السياق
- أريد تصميمًا يسبق السوق العربي والعالمي
- لا أريد شيئًا عاديًا
- أريد شيئًا مبهرًا، راقيًا، موثوقًا، ذكيًا، ومرتبًا
- فكر كأنك تبني أفضل موقع وتطبيق محاسبة ذكي في العالم

ابدأ الآن بإخراج:
1. الرؤية الإبداعية
2. الأسس والقوانين الاحترافية
3. هيكل الموقع الكامل
4. هيكل التطبيق الكامل
5. اتجاه التصميم البصري
6. النصوص المقترحة
7. أفضل تحسينات تجعل المنتج يبدو عالميًا وخرافيًا
